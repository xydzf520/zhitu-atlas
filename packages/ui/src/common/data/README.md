# 招聘城市目录

`boss-cities.json` 提取自 BOSS 公开城市目录：
[城市目录接口](https://www.zhipin.com/wapi/zpCommon/data/city.json)，获取日期 **2026-09-21**，共 **373** 个平台城市条目。

仅保留城市名称、平台搜索代码、省级名称和区县名称，用于本地地址识别、城市选项和构造用户目标城市的搜索入口。未保留接口返回的访问位置、坐标、IP、Cookie 或其他访问环境字段。该文件是平台位置目录，不是法定行政区完整清单；代码可能随平台变化，需要定期核对。

不按区县同名、道路名称或不确定坐标推断企业精确地点。城市与地址冲突、区县归属有歧义时保持待核实。街道地图只使用来源已有或本人确认的 WGS84 坐标。

在线底图使用 Leaflet + 天地图官方 WMTS；使用者在本机配置自己的服务 Key。源码不再包含边界数据，不预取或批量下载离线瓦片。未连接时保留城市／区县数量和地址列表。见 [地图来源与条件](../../../../../docs/MAP_DATA_SOURCES.md)。
