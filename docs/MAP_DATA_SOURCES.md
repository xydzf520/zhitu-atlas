# 地图接入与位置数据

适用 **0.22.1**。源码及客户端不再包含 DataV 边界文件，不再匿名请求高德瓦片，也不加载外部地图脚本。

## 在线地图

使用 Leaflet 展示天地图的 Web Mercator WMTS 服务：矢量底图 `vec_w`、中文地名 `cva_w`、境界 `ibo_w`。三层一起启用，国界、台湾及南海相关内容由提供方底图和境界层呈现，Atlas 不重绘或裁改这些要素。全国视野保留北纬 2–55 度、东经 72–136 度的范围；默认首选城市，支持全国和各城市切换。

使用者在「设置 → 地图」配置自己的服务 Key，并按[天地图控制台](https://console.tianditu.gov.cn/api/key)和[官方服务文档](https://lbs.tianditu.gov.cn/server/MapService.html)核对应用类型、权限及配额。官方地方节点的[接入指引](https://tianjin.tianditu.gov.cn/static/help/note.html)也说明了注册、认证、创建应用和上线前检查流程。天地图并非由 Atlas 重新授权的数据；具体服务条件仍适用。软件不提供共享 Key，不承诺任何用途永久免费。

Key 保存到数据目录下 `private/maps.json`，文件仅当前用户可读写。前端只取得是否已配置及版本号；瓦片由本机后台向固定天地图 HTTPS 域名请求，拒绝重定向，只接受限定尺寸的 PNG／JPEG。请求仅包含图层、瓦片编号和 Key，不传简历、企业名称或详细地址。只请求当前视野；并发受限，重复进行中的请求合并，不批量下载，不持久化瓦片，不自动重试错误。

底图署名保留为天地图／国家地理信息公共服务平台。连接测试验证三个图层返回图像，不等于对服务使用权或当前地图内容的认证。本轮没有真实天地图 Key，三层合成及错误处理使用隔离响应测试，真实账号和地图内容显示仍需配置后核对。

## 未配置与离线

未配置或网络不可用时，显示地图配置／重试入口，并保留地区统计、地址列表、阶段和筛选。**没有内置离线地图**，不再将无授权的本地边界作为失败回退。没有地图时不允许从空白画布选通勤起点；原有起点和企业位置不变。

## 参考点与坐标

城市／区县参考点来自 [GeoNames](https://www.geonames.org/about.html)，© GeoNames，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。数据经过筛选和分组，用于展示地区汇总。373 个地区选项、2,578 个区县参考点。CN/TW/HK/MO 是来源文件编号，不用于本应用的行政归属或国界绘制。

企业坐标仍以确认的 WGS84 数据保存。天地图经纬度显示不再做旧高德 GCJ-02 偏移；WGS84 与服务地理参考体系的差异只适用于一般位置展示，不作测绘精度承诺。手动点选以近似经纬度保存，距离仅为直线距离，非自动通勤时间。GeoNames 汇总点不是企业门牌位置，也不写入企业坐标。

旧坐标转换实现及其 MIT 署名保留用于历史兼容核查，当前天地图显示不调用它。0.22.0 的地图授权核对见[历史报告](LICENSE_AUDIT_20260922.md)。旧 Git 历史仍可能包含已移除地图资产，向外提供源码时使用不带历史的已检查源码包，不能直接将旧仓库全历史转为公开。
