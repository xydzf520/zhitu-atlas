# 0.21.1 本机私有配置验收

## 交付范围

- 模型渠道、模型选择与凭据统一由本机后台读取 `private/models.json`，与源码、业务数据库及前端构建资源分开。
- 首次读取时迁移旧 `config/llm.json`；保留渠道和模型，校验后移除旧副本。冲突、中断或损坏不会静默覆盖。
- 网页和桌面共用同一保存接口；配置版本与进程锁防止并发覆盖。设置接口仅返回已配置状态和私有文件位置。
- 私有文件不进入跨设备备份、源码归档和安装包；同一电脑迁移安装目录可保留凭据，运行锁不复制。
- 新增源码、可达 Git 历史、构建与打包检查；前端不注入 `VITE_*` 配置。
