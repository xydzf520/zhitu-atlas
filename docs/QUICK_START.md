# 拿到 Atlas 后，先这样用

适用 **0.22.1 · Linux x64 桌面**。完整包自带 Electron 和 Chromium，启动与安装都不需要 Node.js、管理员权限或外部浏览器。

## 1. 打开程序

先核对下载文件的 SHA-256，再解压。进入解压目录：

```bash
./start.sh
```

需要在应用菜单保留入口时，关闭客户端后执行：

```bash
./install.sh
```

安装器逐文件校验并保留旧版本。完成后在应用菜单打开「职途 Atlas」。安装目录和资料目录分开，升级不会附带他人的资料或账号。

需要 Linux 图形桌面及 GTK 3、NSS、GBM、ALSA 等系统运行库。本次实测 Ubuntu 26.04 x64；其他 Linux 发行版需要验证。Windows、macOS 包尚未提供。

## 2. 不配置外部服务，也能先用

1. 打开「简历与资料」，粘贴自己的简历，补充工作和项目经历；逐项确认可用于话术的事实。
2. 打开「机会发现」，保存目标岗位、城市、薪资与排除条件。
3. 在「企业与进展」手动添加岗位，或到「设置 → 数据管理 → 岗位导入」导入 CSV／JSON。先预览，再确认保存。
4. 查看公司、岗位、阶段和待办，记录沟通、面试及结果。

空白模板为 `examples/jobs-template.csv`；`examples/jobs-fictional.json` 是两条明确标记的虚构记录，仅用于理解格式，也可在导入页下载。导入不代表投递，不会自动发送消息。

## 3. 按需连接三种服务

| 需要的功能 | 去哪里配置 | 需要自己提供什么 |
| --- | --- | --- |
| AI 匹配、话术和研判 | 设置 → 模型与 AI 用量 | 模型接口、模型 ID 和自己的 Key；也支持本机免密兼容服务 |
| 地图位置与全国／城市切换 | 设置 → 地图 | 自己的天地图服务 Key，并核对权限和配额；保存后测试三种图层 |
| BOSS 采集和沟通 | 桌面 BOSS 工作台 | 自己登录 BOSS；其他浏览器登录状态不会自动共享 |

模型先测试生成与工具调用，再运行实际岗位任务。AI 会向所选服务发送该任务需要的资料；费用由自己的服务配置决定。地图配置及模型密钥只放在本机私有目录，不在代码、安装包或业务迁移备份内。

地图未配置或断网时显示具体原因，地区筛选和地址列表可继续用；不显示伪造底图，不将地区汇总点当成公司精确地址。地图服务的认证、Key 类型、配额及使用条件以提供方为准，软件不赠送账号或共享 Key。

## 4. 再开始联系

新安装的自动任务和发送默认暂停。资料确认、JD 匹配、账号检查都通过后，在「机会发现」检查模式、额度与时段，再点击开始。重要事项和附件简历仍需本人确认。结果不确定时先核实，不重复启动发送。

本机网页可在桌面启动后访问 `http://127.0.0.1:5178/desktop.html`，与桌面共用资料。后台未启动时网页不可用。

## 遇到问题

- 启动失败：在终端运行 `./start.sh` 查看错误；缺少系统共享库时按所在发行版安装相应运行库。不要用 `sudo` 或关闭沙箱解决。
- 端口被占用：先检查是否已有 Atlas。独立测试可设置 `ATLAS_DATA_ROOT` 和 `ATLAS_PORT`，不要删除真实数据库。
- 模型／地图失败：在设置里测试，检查地址、权限与额度。未配置不会影响手动管理资料。
- BOSS 数据未出现：查看任务中心的账号与同步覆盖；登录成功不代表全部历史已同步。

更多安装、迁移与恢复说明见 `docs/OPERATIONS.md`。只提供版本和脱敏错误排查，不把密钥、Cookie、简历或聊天原文发到公开问题区。
