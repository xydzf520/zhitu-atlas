# 13.11 两路岗位发现与 AI 自动联系

版本：`0.17.4+atlas.13.11`，日期：2026-09-20。

## 使用方式与执行范围

机会发现顶部提供「目标岗位搜索」和「BOSS 推荐岗位」，可单选或同时选择：

- 目标岗位搜索使用统一求职策略的核心词与扩展词。
- BOSS 推荐读取当前账号实际推荐的列表，再补完整 JD、分析履历匹配；不需要先填写搜索关键词。
- 选择「匹配后自动联系」和「匹配及事实校验通过后自动发送」，点击「启动所选来源并自动联系」。仍可切换为逐条确认。
- 两路共用候选、详情、AI 和发送预算。按平台、账号、岗位和招聘者去重。切换来源不绕过在途任务：其他来源仍在采集时先等待或暂停该轮。
- 任务保存来源标签；多源岗位保留全部来源，结果按入队时的首个已选来源计数一次。历史联系任务没有来源信息时保留「其他／历史来源待核实」。来源卡按所选期间创建的联系任务统计；待联系总卡仍是当前库存。
- 当前账号、JD、已确认经历、AI 建议与事实审校均通过后才允许自动联系。默认招呼和个性化说明分别计数，后者只有平台消息回读核验后才算完成。
- 自动联系指建立会话及发送匹配说明，不等于发送附件简历。简历附件、正式申请、薪资承诺与面试确认仍需本人确认。
- 自动授权绑定账号、来源、授权版本及具体话术依据。切换账号、关闭自动模式、改变内容或资料使相应授权失效；暂停、冷却、额度和不确定发送不重试规则保留。

## GitHub 项目与话术

只引用已确认经历中的项目。与 JD 相关时，优先用一段完整经历说明匹配关系，并附上已核实的公开仓库地址。项目核实到期后自动刷新；失败保留任务并提示。生成时为 URL 预留字数，不能为了满足长度静默丢弃所选项目链接，也不能截断指标口径。

模型不能编造 URL，不能把代码能力写成业务成果，也不能把开源项目代替必要资历。资料中的 已核实的公开作品 地址已由本人提供的公开仓库更新，并通过公开元数据核实；未向源码仓库写入个人简历、账号或模型凭据。

## 测试证据

- 265 项业务回归通过。覆盖来源路由、跨源去重、来源隔离、未知历史不自动授权、账号隔离、自动发送及消息回读、默认招呼冷却、授权撤销、并发配置版本、启动失败事务回滚、链接核实失败和长话术修复。
- Node / Vue 类型检查、正式网页及 Electron 生产构建通过。构建保留已有大体积 chunk 提示，不影响产物生成。
- 使用独立数据服务检查真实前端：两路勾选、未选来源禁止启动、推荐独立启动、自动模式状态、暂停发送、来源筛选和键盘操作。1280×720、1920×1080 下未发现页面横向溢出，未记录浏览器错误。
- 使用当前 CommandCode 配置中的 `deepseek/deepseek-v4.1-flash`，以已有真实 JD 和本人已确认履历在隔离数据目录调用新版服务。205 字话术包含 已核实的公开作品 GitHub URL；事实、相关性、简洁度、无承诺四项审校通过。生成与独立审校共 2 次模型调用，53,435 tokens，耗时约 232 秒。继续保留用户的 max 参数，没有降低模型配置。
- 同一真实 JD 的完整岗位分析复测通过，返回 9 项要求和 16 次经历证据引用，建议为「可以考虑」。实际调用 1 次、58,906 tokens，耗时约 276 秒。话术测试与岗位分析均使用隔离数据，没有启动真实平台发送。
- 正式客户端已安装并重新启动，版本核对为 13.11；本机接口、来源入口、来源统计均可用，自动模式不再自动弹出旧待确认草稿。模型配置保持一致，每日 20 条消息、10 次首次联系及发送暂停状态保留。
- 本轮实际发送招聘消息为 0。隔离适配器核验不能代替当前 BOSS 页面真实开聊、发送和消息回读；真实执行仍以平台凭据为准。

## 升级与回滚

本轮没有新增表。开始前已通过 SQLite 在线备份及完整性检查，资料更新使用服务版本校验并保留历史。安装采用 `scripts/atlas-install.cjs` 的归档校验、原包备份和原子替换。升级不自动解除现有发送暂停，不提高每日额度。

回退：退出客户端，使用安装输出记录的旧 `app.asar` 和 SHA-256 通过同一脚本安装；回退前保持发送暂停。旧版本不会实现本轮来源选择与自动话术授权。私有备份、模型结果和安装包仅保存在本机 `artifacts/dual-contact-20260920`，不提交 Git。
