# 沟通中心信息结构与布局验收

> **历史版本记录**：正文只描述文内日期和版本。功能、测试数、路径及回滚命令不代表当前版本；现行操作见 [使用指南](USER_GUIDE.md) 和 [运行与升级](OPERATIONS.md)。原有测试结论保留，不追认为本轮复测。

版本：0.17.4+atlas.13.6；日期：2026-09-19。

## 变化

- 三个功能入口：会话沟通、待确认与发送记录、自动回复设置。同步范围、缺项和近 30 天样本复盘默认折叠。
- 会话页分为联系人、消息与草稿、下一步与关联岗位。优先选择待处理会话，列表、聊天和侧栏独立滚动；在较小屏幕压缩页面头部。
- 搜索、状态、联系人与历史消息分页继续使用原服务。BOSS 未读与 Atlas 提醒分别展示，查看 Atlas 提醒不标记 BOSS 已读。
- 回复草稿按账号＋联系人隔离，保存在当前浏览器会话的 sessionStorage。切换联系人、功能页或刷新后保留；生成期间本人修改优先，模型失败保留原文，新消息明确提示上下文过期。
- 查看旧历史消息时禁止用旧上下文生成回复；后台拒绝来自已变更账号的草稿请求。生成、编辑与复制均不创建发送指令。
- 待确认项明确区分对方消息、处理原因、回复内容、发送状态；支持从联系人跳到其待确认列表，再返回完整会话。原有具体内容确认、暂停、额度及核验规则保留。
- 切到回复设置或待确认页时停止聊天列表轮询；保留已加载会话和草稿。
