# 0.22.0 通用求职版本

后续 0.22.1 已完成独立分发、无 Node 安装、地图配置及无历史源码快照，见 [当前交付](DISTRIBUTION_0221.md)。下文保留本版验收范围。

基线：0.21.2。已有用户资料、已保存策略和模型参数保留；不开启现有账号的自动发送。

## 改进

- 回复地点根据本人目标城市生成，百分比口径由所引经历约束，不再固定套用作者的上海覆盖率；简历诊断使用目标职业的专业实践依据。
- 职业匹配移除产品方向固定加分；常见职业别名使用相同权重，未确认经历不提高初筛资格，未知方向保留待核实。规则改变后旧分析通过提示词版本失效。
- 支持自定义 Chat Completions 兼容接口、手填模型 ID／读取模型目录，以及本机回环免密服务。密钥绑定具体地址，禁止重定向。
- 新配置默认 4K 请求上限，可选择按任务缩小输出或固定上限；思考参数、JSON 模式、工具能力显式配置。旧配置没有新选项时保留原行为。
- 总览和设置提供首次使用清单及四种职业的虚构示例，示例不调用模型、不入库、不执行发送。
- 新安装自动任务与发送暂停，现有持久化策略不被覆盖。
- 真实评估按当前账号选择岗位和已确认经历，不依赖作者的岗位 ID、GitHub 仓库或旧模型文件。来源目录可配置；评估在快照运行，不迁移或修改来源配置。
- 补充许可证、第三方许可归档、隐私与参与说明、中英文首页、CI 构建附件和标签触发的草稿发行。
- 总览和全局分析共用薪资分布，按当前样本调整区间，避免低薪样本都挤在「30K 以下」；未知薪资不入统计。
- 独立数据目录可通过 ATLAS_PORT 选择回环端口，测试不抢占生产端口。

## 升级和回滚

本次没有新增数据库 schema。升级前退出旧版后按运行指南安装完整包；已有模型首次读取按私有配置迁移规则处理。恢复旧客户端前请使用升级前的配置备份：旧版不识别新兼容渠道与新私有目录，不能把模型记录简单覆盖回源码。

地图数据仍属于第三方。核对后，当前 DataV 边界再分发授权与高德底图接入许可仍缺乏充分依据，**包含当前地图资产的源码和完整客户端尚未通过公开发行许可核查**；许可证清单和本地几何测试不替代来源方授权，详见地图说明。
