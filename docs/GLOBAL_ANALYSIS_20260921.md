# 0.19.0：全局分析与全国地区视图

日期：2026-09-21。项目：职途 Atlas。

## 本轮内容

- 「全景总览」下增加「全局分析」：资料准备环图、地区和薪资分布、条件核对、当前证据矩阵与优先处理项。
- 新增简历竞争力诊断、市场机会研判 Agent，与提示词编辑、启停、版本和用量共用服务；任务后台执行、可取消、跨窗口去重。
- 分析围绕整份履历，从 HR 核对和业务交付两个视角提出具体建议。每项结论和行动引用来源，优势必须有确认依据，机会必须引用岗位。
- 按当前账号、最近 30 天／90 天／全部记录统计。重复来源归一，账号待归属记录不混入；未知日期、薪资、地点单列。
- 统计覆盖窗口内全部岗位；模型阅读最近 60 份 JD 摘要及当前资料。不外推全国人才供需，不展示虚构竞争力总分或录用概率。
- 全国城市／区县分布与列表、阶段、统计联动；搜索使用已保存的城市。移除上海专用地图与未使用边界资源。
- 街道地图只绘制有效 WGS84 点位，保留署名、按当前视野加载；区域汇总离线可读。修复 OSM 规范瓦片主机与 CSP 不一致。
- 收拢总览的重复诊断；精简页面装饰性英文、口号与重复说明；统一系统字体、日间色和标题层级。长研判默认前三项，其余按需展开。

- 完整回归 **310 / 310 通过**，Node / Vue 类型检查通过，网页与桌面生产构建通过。记录：`artifacts/global-analysis-20260921/release-check-final.log`。

- 新增 18 项隔离检查：全国城市识别、同名与冲突地址、城市代码、多城市来源、账户隔离、窗口和薪资分母、重复来源、当前分析版本、事实引用、缓存、取消、输入改变、持久任务去重，以及 Agent 工具协议的证据编号回传、平台原始岗位编号映射与歧义拦截。

- 市场修复实测通过：**6 项结论、5 项建议**，模型真实调用 1 次只读证据工具，完成 2 轮模型请求；最终引用全部为当前来源编号。证据：`live-market-final-result.json`、`market-final-reference-diagnostics.json`。最终窗口提示修正后再次通过类型检查与生产构建（`final-window-types.log`、`final-window-build.log`）。

- 最终安装包通过本机 HTTP → 持久任务 → 分析服务 → 报告读取验证：两项均命中已生成报告，不重复调用模型（`final-cache-results.json`）。页面两份报告均显示，无失败或过期提示；30／90 天窗口状态独立。
