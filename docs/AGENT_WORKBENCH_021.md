# Agent 运行台：0.21.0

2026-09-21。此版本将已有执行器接入可追踪的运行台，不新增另一套发送或调度系统。

## 从哪里使用

打开 **任务中心 → Agent 运行台**。总览、机会发现、沟通中心及 Agent 管理中的“查看工作进度”进入同一份记录。

1. 左侧选择岗位或会话，查看当前步骤和待处理原因。
2. 中间选择主安排、子任务、模型或程序步骤；只有实际发生的调用才显示模型步骤。
3. 右侧查看拟回复、分析结果、经历依据、提示词版本和增量运行记录。
4. 需要调整时，暂停本条流程、取消或明确重新生成；编辑和重要事项确认回到原岗位、会话入口。

宽屏使用三栏；较窄窗口将步骤横向排列。各按钮支持键盘操作。长报告按原有结构展示，无原始 JSON 默认输出。

## 已打通的协同

| 链路 | 如何追踪 |
| --- | --- |
| 求职协调 → 模块执行 | 计划派发时关联实际 taskId、contactId、discoveryId，保留上下级和来源；规则安排与模型安排区分 |
| 岗位发现 → 分析 → 策略复盘 | 发现轮次、每个岗位分析及扩展词调整关联；可看到等待条件和实际子任务结果 |
| 自动联系 → 话术 → 审校 → 发送 | 同一联系任务记录模型、程序检查、消息预留和结果凭据；草稿不计发送成功 |
| 会话 → 回复 → 经历证据 | 同时按账号、岗位和联系人检索关联流程；重要事项直接显示待本人处理 |
| 企业研判 → 来源与更新 | 显示研判结论、业务联系、推断、公开来源及工具步骤；返回会话查看完整历史 |
| 全局分析／面试准备 → 改进与证据 | 简历、市场及面试任务沿用同一队列，结果与当时资料版本绑定 |
| Agent 管理 ↔ 运行记录 | 从实际模型步骤查看当次提示词版本；从调用记录进入所属工作 |
| 备份、恢复与异常处理 | 运行关系进入加密备份；恢复后未完成工作中断，不能自动重放模型调用或发送 |

同一结果只有一个执行归属，不通过相似公司名、任务时间或标题猜测父子关系。协调器完成安排后，子任务仍分别显示自身进度。模型调用串行、平台账号串行沿用已有租约，工作树不代表各模型并行执行。

## 结果与控制边界

- **候选话术**：模型已返回，尚未完成全部业务检查；审校过程中也能阅读。
- **已保存结果**：生成与业务处理完成，仍不代表发送；显示实际经历引用和资料版本。
- **平台核验**：展示实际尝试文本、消息凭据和核验方式；人工确认与平台回读分开。
- **结果不确定**：保留记录，回到发送核验入口处理，不自动重发。

暂停本条只影响这条流程及其自动派发后续步骤；不修改全局策略。取消、失败、进程中断的模型调用不能直接恢复，需本人创建新任务。重新生成保留旧结果，可附加本次表达要求，但不改写经历、全局提示词或发送权限。

所有控制携带版本，跨窗口冲突不会覆盖草稿。AI 输出不能更改程序授权；已在途的请求可能已计费，已发出的消息无法由取消动作撤回。

程序记录实际完成的分类、事实与表达检查、独立审校、发送核验，不把尚未执行的检查画成绿色。模型内部 reasoning 和密钥不进入运行事件；工具步骤只记录名称、状态和安全摘要，完整来源在对应报告查看。

## 数据与接口

SQLite 显式迁移至 schema 7，新增 `execution_runs`、`execution_steps`、`execution_links`、`execution_events` 和 `execution_subjects`。现有 task、AI call、send attempt 保持业务归属，通过稳定 ID 关联。

桌面与网页共享 `career-execution-list/detail/events/control` 处理器。列表每页 20 条、事件按游标每批 100 条；查询按账号隔离。订阅复用，页面隐藏停止轮询，离开释放监听；没有以虚假百分比表示长模型调用。

旧版任务仍可在执行队列和调用历史查看。升级前未保存的逐步轨迹不会补造。单条运行最多读取 300 个步骤、100 项子工作，更长流程可查看事件并进入所属模块。

## 尚可继续增强

这轮完成执行链路与页面入口接入。原设计中以下增强没有伪称完成：按日期和任务类别的组合筛选、跨任务依赖的全图编辑、在运行台内直接编辑并发送重要事项、企业研判事实自动进入回复依据、完整七维人工可读评审面板。当前使用实际规则检查和原业务页面处理，避免新增一个与现有草稿／发送权限冲突的入口。

下一轮协同可优先做“企业研判结论 → 本人核实 → 可引用业务事实 → 回复／面试准备”，以及“真实回复、面试进展 → 周期复盘 → 搜索词建议”。所有反馈需保留样本、来源和版本，不能把未回复自动解释为拒绝，也不能让优化过程放宽薪资或自动发送规则。
