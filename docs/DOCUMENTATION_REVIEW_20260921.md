# 文档与项目描述审查

日期：2026-09-21。对象：职途 Atlas **0.18.0**。本轮核对项目说明、全部现有 Markdown 文档及相关代码入口；文档说明以实际实现为依据，不把原计划直接当作已完成能力。

## 已修正的主要问题

| 原先容易误解的地方 | 当前说明 |
| --- | --- |
| 旧目录、旧包安装方式与现行操作混用 | README 指向独立客户端与新数据目录；旧版本记录保留并标明历史范围 |
| “自动投递”被理解为已经发送简历 | 区分开聊、匹配说明、实际附件／申请、平台回读和人工确认 |
| 历史逐条确认要求与当前自动发送选项冲突 | 说明机会发现的两种授权，以及手动草稿确认、常规回复和重要事项各自的规则 |
| 新用户默认就有上海、40K 和个人经历 | 新资料为空；已有用户迁移保留本人策略，程序初始额度与个人偏好分开说明 |
| 所有后台任务与写入都经过 HTTP | 原生 BOSS 工作器在桌面主进程，通过 Atlas 存储模块访问同一 SQLite 库 |
| 本地保存被理解为资料从不外发 | 列明模型、企业搜索、GitHub、地图和 BOSS 的实际数据流 |
| 同机迁移、加密迁移和普通升级混为一谈 | 说明凭据保留差异、恢复替换行为和暂停条件；普通升级不承诺自动暂停 |
| 每日 30 次预算被理解为必定完成 30 个岗位 | 按生成请求计数，工具续轮也占预算；缓存与调用分开 |
| 1M／384K 和历史模型数量被写成实时服务保证 | 区分本地请求参数、目录返回值与服务商实际支持；标注历史快照 |
| 模型 45 分钟超时含义不明确 | 分开说明租约等待上限与取得租约后的执行计时 |
| 地图点位来源表述过于绝对 | 区分来源坐标、手动定位、行政区及未知坐标系，不将距离当通勤时间 |
| 本机没有发送记录被解释为账号没有沟通过 | 0 条仅描述当次 `send_attempts` 表，不推断完整平台历史 |
| 重构被理解为所有安全问题均关闭 | 保留原安全评审，对照已移除路径、已有控制和仍待改进项 |
