## 功能

- 资料的每条经历可关联项目名称、公开仓库、本人贡献和能力边界。保存在统一资料版本中，编辑后原确认失效。
- 岗位推荐、招呼与沟通话术共用同一份项目上下文；只展示实际引用的相关项目。通用产品经验、岗位硬条件和项目证据各自保留。
- GitHub 公开状态、非空仓库和可识别许可证由服务端核实；仅允许仓库首页 HTTPS 地址，不访问内网或任意链接，不使用 GitHub 私有凭据。
- 核实有效期 24 小时。未公开、未确认、过期或缺少许可证的项目不附开源链接；核验不替代个人贡献确认。
- AI 选择对应经历，程序再按长度预算附上至多一个已核实链接；模型不能自行生成链接。能力边界同时进入生成与事实审校。
- 真实话术测试发现经历片段直接拼接且首尾重复询问；审校正确拦截后，补齐句间标点、限制开头只描述岗位需求，并提示优先使用一段相关短句。保留独立审校与最多一次修复。
- 项目状态、资料、JD、模型或提示词变化会使旧结果失效；本人确认、发送限额、暂停和结果核验继续生效。

## 升级和回退

本轮没有新增数据库表。安装脚本保留旧 `app.asar` 和升级前数据库备份。回滚时退出客户端，使用 `scripts/atlas-install.cjs` 安装备份归档并校验 SHA-256；通常无需回退业务数据。旧版不具备本轮项目核实门槛，回滚前继续保持发送暂停。

公开源码、项目权属、模型训练效果和平台真实发送是独立验收项；此功能不会将其中任何一项自动视为已完成。
