# 数据与隐私

Atlas 没有公网用户账户服务。简历、岗位、对话、任务记录及附件保存在本人选择的本机数据目录。

| 功能 | 外部请求与数据 |
| --- | --- |
| 手动编辑与机会管理 | 本机保存，无需模型或招聘平台 |
| AI 分析、话术、面试准备 | 将本任务需要的经历、JD 或已同步对话发送至本人选择的模型接口；不等于离线推理 |
| BOSS 连接 | 使用本机独立登录会话；读取到的页面、消息与岗位按来源归档，不能保证全历史覆盖 |
| 企业研究／作品核实 | 查询公开搜索页面、企业网页或本人添加的公开 GitHub 仓库 |
| 在线地图 | 向天地图请求当前视野瓦片；不上传完整简历与聊天，数据源说明见地图文档 |
| 模型目录 | 用户选择渠道或点击读取时，请求相应服务的模型列表；自定义地址的密钥只发往该地址 |

新安装无个人资料，自动任务与发送暂停；查看虚构示例不联网、不入库、不调用模型。已有安装保留本人策略。是否关闭网页与是否暂停后台是两回事，请用任务开关控制自动化。

模型文件权限为 0600、私有目录为 0700，是操作系统权限隔离，不是本机加密保险库。拥有同一系统账号权限的人仍可能读取；本机接口也不用于多用户服务器托管。

加密迁移备份不含模型密钥和平台会话；原始数据库和整目录备份包含私人数据。项目报告、Issue 与公开截图使用虚构或脱敏数据。

清理数据前先退出程序并按需导出备份。卸载程序不会自动删除简历和对话；数据目录、浏览器会话目录及清理方法见 [运行指南](OPERATIONS.md)。

地图服务 Key 位于本机 `private/maps.json`，不返回前端、不随业务备份迁移。仅向固定服务域名发送瓦片编号与 Key，不发送简历、企业名称或工作地址。图像只在当前会话展示，不保存在磁盘瓦片库。
