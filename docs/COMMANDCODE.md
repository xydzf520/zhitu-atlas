# 模型渠道、参数与工具

适用：职途 Atlas **0.22.0**，按本地实现核对。桌面与网页共用「设置 → 模型与 AI 用量」；这里描述软件当前发送的配置，服务商支持能力与账号权限以实际返回为准。

## 选择与测试

1. 选择 CommandCode、DeepSeek 或自定义 Chat Completions 兼容接口。新安装没有预选模型；配置地址后可手填模型 ID，也可读取服务的模型目录。已有配置以保存值为准。
2. 输入密钥并保存。同一渠道切换模型时留空可以保留该渠道已存凭据；切换到尚无凭据的渠道需填写相应密钥。
3. 点击「测试生成与工具调用」。该操作创建后台诊断任务，使用隔离样例、调用真实模型，会消耗模型额度；诊断最多等待 2 分钟。
4. 查看生成、工具调用和错误分别是否通过。只返回文字不等于通过工具调用测试；目录可见不等于当前套餐允许调用。
5. 在 Agent 管理中修改业务提示词或启停，查看版本和实际系统提示词快照。它们不赋予模型发送授权或资料确认权限。

CommandCode 模型目录保留全部返回条目，按 `supported_endpoints` 路由：优先 `/chat/completions`，仅支持 `/messages` 的模型走 Anthropic 协议。未知端点模型仍可见，但不能保存为执行模型。自定义接口使用 Chat Completions 协议，不根据模型名称猜测其他协议。

| 渠道 | 本地实现使用的地址 |
| --- | --- |
| CommandCode 目录 | `https://api.commandcode.ai/provider/v1/models` |
| CommandCode Chat | `https://api.commandcode.ai/provider/v1/chat/completions` |
| CommandCode Anthropic | `https://api.commandcode.ai/provider/v1/messages` |
| DeepSeek 官方 | `https://api.deepseek.com/chat/completions` |

## 自定义接口与通用预算（0.22.0）

设置支持 CommandCode、DeepSeek 与自定义 Chat Completions 兼容接口。兼容地址由本人明确填写：远程只接受 HTTPS，本机免密模型可使用 `http://127.0.0.1:端口/v1`。填写模型 ID 后保存，可读取该地址的 `/models`；服务未实现目录时仍可手动填写。

密钥按完整兼容地址绑定，不自动复用其他地址的密钥，不跟随接口重定向。进入设置不会自动访问未保存的兼容地址。

新保存配置默认最大输出 4096 tokens，按任务进一步限制：短话术 2048、模型诊断 1024，分析等任务不超过设置上限。可以选择固定上限；思考、JSON 模式与只读工具按接口支持情况启用。模型能力未返回时显示未知，不将全部模型写成 1M。

旧配置未设置新选项时仍沿用旧参数，包括 DeepSeek max／384K。下方的历史参数表描述该兼容行为，不是新用户默认值或服务商最新能力保证。保存后可以使用虚构样例测试实际生成与工具回传；不支持的参数会明确报错，不偷偷切换模型。


## 旧配置兼容：max、上下文与输出

| 项目 | 旧配置未保存新选项时的行为 |
| --- | --- |
| DeepSeek 思考 | `thinking: { type: "enabled" }`，`reasoning_effort: "max"` |
| DeepSeek 请求输出预算 | `max_tokens: 393216`，即 384 × 1024 |
| CommandCode 上下文 | 显示渠道目录返回值；缺少值时显示未知，不写死为 1M |
| 官方渠道上下文显示 | 本地配置常量 1,048,576；不是每次请求都会提交的参数，也不是本轮对官方能力的重新认证 |
| 其他模型 | 当前请求预算 4,096 tokens，不发送 DeepSeek 专用思考参数；Anthropic 使用原生消息协议 |
| 业务调用超时 | 排队等待上限 45 分钟，取得模型租约后的执行另设 45 分钟计时；不是从点击到结束严格合计 45 分钟 |

输出预算不等于模型每次都会生成这么长，也不证明渠道允许这个最大值。若目录或调用返回不支持，以实际错误为准；当前实现不会默默降低用户保存的配置来宣称成功。历史目录曾返回的 1,000,000 tokens 或 71 个模型，只是当时快照，不是当前保证。

## 哪些工具可以使用

| 用途 | 工具与范围 |
| --- | --- |
| 诊断 | `atlas_connection_probe`，固定参数的本地只读探测 |
| 经历核对 | `atlas_read_confirmed_evidence`，只读取本次输入中已提供且已确认的经历 ID；常规挂载由模型设置的「常规任务允许经历查询工具」控制 |
| 企业研判 | `search_company_public`、`read_company_public`，检索企业公开资料，读取本轮获准的来源 |

通用传输最多 3 轮模型请求、通常最多 4 次工具调用；企业研判允许最多 6 次工具调用，仍受请求轮次和搜索／阅读次数约束。自动策略复盘不额外挂载经历查询工具。模型不能调用任意代码、读取任意文件、浏览内网、修改经历或直接发送招聘消息。

企业搜索直接读取公开 HTML 页面，没有第三方搜索 API 密钥。无法访问的网页、验证页、资料不足和主体不确定会保留在结果中，不自动补全事实。

## 用量、失败与数据

常规 AI 回复和首次招呼都有生成与独立事实审校两个阶段。审校 Agent 为「话术事实审校」，在常规回复中使用对应变体；检查数字以外的能力、职责与成果是否有证据。未通过或审校 Agent 停用时不生成可自动发送的新回复。生成和审校各记用量；工具续轮可能增加实际请求数。重要事项在进入模型前拦截，命中缓存的回复不重新调用两阶段。

每次生成 HTTP 尝试计入实际用途和用量；自动岗位分析的工具续轮也占每日预算。缓存命中不等于一次新的生成。超时、网络结果不确定、输出格式错误或未经授权的工具会停止任务，不静默重试可能已计费的请求。旧结果与草稿保留，修改模型、资料或提示词后按业务依据重新核实是否过期。

默认提示词也有内容指纹；程序升级改变默认提示词时，相关旧缓存会失效。排队任务绑定创建时的资料、策略、模型和提示词依据，派发前变化则中断，避免以旧请求默默生成新资料的内容。取消支持中止已建立但长时间未输出的流响应；请求可能已产生费用，取消不代表退款。

凭据保存于 `~/.local/share/zhitu-atlas/private/models.json`；设置接口不会返回已保存的密钥。业务 AI 会把任务需要的资料发送给所选模型服务，不能把“本地保存”写成“从不外发”。系统提示词快照、工具名称和用量保留在本机；任务输入及结果也可能含个人资料，因此数据库和原始备份同样需要妥善保存。

同机升级可保留模型配置；加密迁移包不带 API 密钥，新电脑需重新配置。详见 [运行与升级](OPERATIONS.md)。
