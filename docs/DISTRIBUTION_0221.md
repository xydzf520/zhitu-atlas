# 0.22.1 独立分发与首次安装

本轮目标：新使用者拿到完整 Linux 客户端或源码快照后，可以按指引启动、录入资料、导入岗位并按需连接自己的模型、地图和招聘账号。

## 交付变化

- 完整包提供 `start.sh` 与 `install.sh`；启动及安装复用内置 Electron／Node 运行时，无需单独安装 Node.js，不需要 sudo。安装器保留逐文件哈希校验与版本回滚。
- 补充首次使用指南、空白 CSV 模板和虚构 JSON 示例；导入页可下载，先预览再提交，不自动灌入示例数据。
- 移除 DataV 边界原文件及匿名高德瓦片接入，改为天地图三层 WMTS，由用户自己的服务配置启用。Key 本机保存、读接口不回传、不进业务备份；拒绝重定向和异常图像，最多 8 个并发请求。
- 保留全国／城市选择、企业聚合、阶段颜色、已确认坐标与区域汇总区分。没有地图配置或网络失败时保留地址列表及地区筛选，不冒充存在离线底图。
- 增加不含 Git 历史的源码导出、文件清单及校验值。源码检查兼容没有 `.git` 的压缩包，防止普通用户拿到源码后因 Git 检查无法构建。
- 现有用户资料、模型配置及发送规则保持原值；全新安装的自动执行暂停。

## 功能准备条件

| 功能 | 首次使用条件 |
| --- | --- |
| 资料、机会、阶段、导入和本地统计 | 直接使用，不需要第三方账号 |
| AI 匹配与话术 | 配置自己的兼容模型服务并测试；远程调用可能产生费用 |
| 地图 | 配置自己的天地图 Key、权限及配额；需要联网 |
| BOSS 读取与沟通 | 桌面工作台登录自己的账号；按具体平台状态核验 |

## 验证与边界

验证日期 2026-09-22，全部使用独立数据目录；不存在真实招聘测试消息。

| 检查 | 结果 |
| --- | --- |
| 无 Git 的干净源码 | `pnpm install --frozen-lockfile`、503 项测试、Node／Vue 类型检查、网页与桌面生产构建通过 |
| 完整客户端 | 两端共用 SQLite；全新资料为空、自动任务暂停；后台异常恢复与第二窗口复用通过 |
| 首次业务流程 | 虚构岗位导入预览、确认入库、重复导入识别通过，始终未发送消息 |
| 模型设置 | 实际表单保存本机免密兼容配置、读取模型目录、完成两轮 HTTP 工具调用；本地模型桩，不计作真实服务商验收 |
| 地图 | 实际表单保存本机 Key 且清空输入；三层合成图像加载、错误回退、地址列表可用；使用隔离响应，未借用真实 Key |
| 凭据与网络 | 地图配置权限 0700／0600、版本冲突、移除 Key、固定域名、拒绝重定向、图像校验、8 路并发限制通过 |
| 无系统 Node 安装 | 从 PATH 移除 Node，以包内运行时执行 `install.sh`；路径含空格，菜单创建和 `start.sh` 启动均通过 |
| 升级恢复 | 安装器原子切换、升级、回滚及损坏拒绝测试通过 |
| 许可与源码检查 | 网页输出的 21 个 npm 依赖具备文本；当前源码检查无规则命中；旧 Git 历史发现 2 个已移除地图对象，因此不随分发源码提供 |
| 布局 | 1280×720、1920×1080 的既有页面、首次引导、模型设置及地图连接状态检查通过 |

地图真实服务的权限、配额和内容仍需要使用者配置后核对，合成瓦片测试不能证明真实底图已验收。首次无 Key 时呈现明确的配置入口，手动资料与岗位管理可以正常使用。

复现：`pnpm check`、`node scripts/atlas-license-web-check.mjs`、`node scripts/atlas-runtime-check.cjs <客户端目录> <证据目录>`、`node scripts/atlas-install-smoke.cjs <客户端目录> <证据目录>`。本机证据位于忽略提交的 `artifacts/distribution-0221/`。

完整包的验证平台为 Ubuntu 26.04 x64 图形桌面，其他 Linux 发行版尚需验证；Windows／macOS 未提供正式包。Linux 系统需有 GTK 3、NSS、GBM、ALSA 等运行库。

原 0.22.0 许可检查中的 14 个构建／安装依赖文本待补项仍如实记录；网页实际输出依赖文本已经核对。Electron 保留自身及 Chromium 许可，本轮不冒称完成所有原生组件的独立许可审计。

旧私有仓库历史仍可能包含已移除地图资产，本轮不重写或公开原 Git 历史。向外提供的是已经检查的源码快照；建立公开仓库时应从该快照开始，并保留许可证及来源档案。
