# 0.18.0 独立内核改造与验收

日期：2026-09-21。升级基线：0.17.4+atlas.13.12。当次客户端：**0.18.0**。本页是发布时验收快照，不是对后续运行状态的实时承诺。

## 改造范围

根据之前的源码与运行路径审计，审计涉及 174 个上游来源代码文件：165 个路径已移除，9 个必要入口在原路径重新实现。退出运行链的内容包括：

- 8 个旧工作区包：开聊程序、启动器、进程管理、SQLite 插件、公共工具、钉钉插件及相关包装包。
- 旧自动开聊和跟进循环、Puppeteer 平台执行链、TypeORM 原生扩展。
- 旧 renderer / preload 启动、可读写任意配置的 IPC、旧页面和浏览器设置。
- 旧更新轮询、发布流程、推广图片、旧图标及已停用模拟盘的后台接口。

保留现有 Atlas 的资料、匹配、模型、Agent、同步、沟通、企业研判、联系人、面试与统计业务；没有删除用户此前的业务改动。通用第三方组件继续使用 Electron、Vue、Element Plus、Node SQLite、Leaflet、fflate。Puppeteer 仅用于开发测试，不在生产包内。

历史来源文档、旧 URL 的重定向、只读旧数据迁移仍保留。BOSS 平台本身的 `/web/geek/` 地址属于平台路径，不是旧软件代码。

## 独立实现

| 部分 | 结果 |
| --- | --- |
| 桌面入口 | 单实例窗口、后台健康检查、受限 IPC、独立身份与数据目录 |
| 本机服务 | Electron utility process；HTTP 仅回环监听，校验 Host / Origin / token |
| 生命周期 | 重复后台在绑定端口阶段退出；崩溃恢复有次数上限；不重放结果不确定的调用 |
| 预加载桥接 | 仅业务调用和少量原生操作，事件不暴露原始 Electron 对象 |
| BOSS 浏览器 | 使用内置 Chromium；独立窗口共享会话，可采集消息和岗位详情；任何窗口中的用户草稿优先 |
| 生产构建 | Node 内置 SQLite，无旧原生模块重编译；独立打包完整 Electron 和前后端资源 |
| 安装 | 清单哈希、逐文件校验、路径与符号链接检查、安装锁、原子切换及旧版本保留 |

另外修复了两处稳定性问题：公开仓库重新核实但事实未变时，不再因为观察时间变化使全部分析失效；系统时钟回退时，不重新启动已处理或已暂停的每日挖掘。

## 重复验证与回滚

```bash
pnpm check
node scripts/atlas-native-checks.cjs artifacts/native-checks
node scripts/atlas-package.cjs artifacts/releases/new-release
node scripts/atlas-runtime-check.cjs artifacts/releases/new-release artifacts/client-check
```

原生检查需要 Linux 图形会话；完整客户端界面检查另需测试用 Chromium。所有脚本使用隔离数据。

0.18 之后的客户端回滚：退出程序，用 `atlas-install-release.cjs` 安装上一版完整目录和其清单哈希，安装器切换 `current`，保留其他发布目录。

返回本次升级前版本：先退出 0.18，使用本机保留的旧客户端及原始数据目录；旧启动入口备份是 `previous-launcher.desktop`。不要把新库覆盖旧库；若新版本已新增资料或记录，应先导出备份并核对后处理，避免丢失新数据。源码恢复使用本机 `source-before.tar.gz` 和 `history-before.bundle`，其中包括改造前未提交的工作。
